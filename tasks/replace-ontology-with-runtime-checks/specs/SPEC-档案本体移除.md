# 任务验收：档案本体移除

本文件列出任务完成时应从现行稳定规格清理的旧要求，不新增同名稳定规格。

## 清理的旧要求

### 要求： 字段语义注册
**原因**： 不同机构的真实字段已经由固定字段和分类元数据定义，额外字段语义注册形成第二套映射且没有进入业务事务。

**迁移方式**： 当前 `0.0.1` 不迁移旧字段语义数据；运行时约束和规则直接使用稳定固定字段代码、分类编码与字段编码重新定义。

### 要求： 移除通用本体配置
**原因**： 本变更完成现行本体能力的整体删除，不再需要以“移除通用本体”作为长期业务能力存在。

**迁移方式**： 删除现行本体/字段语义 API、页面、权限文案、代码包、稳定规格、旧 DDL 和相关已归档变更，不保留历史兼容内容。
