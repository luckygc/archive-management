# 进行中的任务

每个目录包含 `SPEC.md`（目标、范围和验收文件）、`plan.md`（技术计划）、`todo.md`（任务与验证）。`specs/` 子目录按 `SPEC-中文能力名.md` 记录任务完成后应满足的要求，以及需要清理的旧要求。项目共同约定见[项目总规格](../SPEC.md)，当前稳定要求见[能力规格](../specs/README.md)。

- [档案信息包接收](add-archive-package-intake/SPEC.md)
- [档案业务库与实物管理](add-repository-and-physical-management/SPEC.md)
- [移除分类方案](remove-classification-schemes/SPEC.md)
- [替换管理表格实现](replace-element-table-with-tanstack-v9/SPEC.md)
- [以运行时约束替换本体](replace-ontology-with-runtime-checks/SPEC.md)

任务完成后，先将最终验收要求并入稳定能力规格，再移除对应任务目录。已有任务的完成状态和验证记录保持原样。
